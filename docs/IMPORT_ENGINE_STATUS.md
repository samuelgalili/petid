## חיבור הכול — מה צריך לקרות לפני שזה רץ בפרודקשן

### א. הרצת מיגרציות
עשר מיגרציות חדשות (0017–0026). הן רצות דרך `node src/applyMigrations.js` עם ledger ו־checksum, כל אחת בטרנזקציה.

**סדר קריטי:** 0017 מחליף את `business_products` ו־`scraped_products` בטבלה אחת עם views. אם משהו חיצוני כותב ישירות לטבלאות האלה — צריך לבדוק אותו לפני.

**נקודת אל־חזור:** 0017 משנה שם לטבלאות המקוריות (`_legacy`) ולא מוחק אותן. גיבוי לפני, כרגיל.

### ב. משתני סביבה
אין חדשים. `@e965/xlsx` נוסף ל־`server/package.json` — צריך `npm install` בשרת.

### ג. מה נדלק אוטומטית
ה־worker של התור מתחיל עם השרת. אין תהליך נוסף להריץ.

### ד. בדיקות שכדאי להריץ אחרי הפריסה
```bash
# בדיקות סכימה מול DB אמיתי (על עותק, לא על פרודקשן)
TEST_DATABASE_URL="postgresql://..." npm test
```

### שאילתת הכפילות
```sql
select lower(btrim(sku)) as sku_normalized,
       count(*) as products,
       string_agg(id::text, ', ') as product_ids
from public.products
where sku is not null and btrim(sku) <> '' and deleted_at is null
group by 1
having count(*) > 1
order by 2 desc;
```

## באגים שנתפסו תוך כדי בנייה

מתועדים כאן כי כל אחד מהם היה מגיע לפרודקשן:

1. **מוצרים לא־מבוקרים היו גלויים בחנות** — ה־view סינן מה להסתיר במקום מה להראות, ולכן 267 מוצרים ממתינים הופיעו למכירה. תוקן ב־0023.
2. **אי אפשר היה לקנות מוצר מגורד** — ה־view לא חשף `stock_status` שהקופה שולפת. תוקן ב־0020.
3. **מוצר חדש שני נעלם מרשימת השינויים** — האינדקס הייחודי מיזג מוצרים שאין להם עדיין מזהה. תוקן ב־0025.
4. **מספרי שורות הצביעו לשורה הלא נכונה** בקובץ — האינדקס נלקח מרשת שכבר נוקו ממנה שורות ריקות.
5. **תיקון נתיבי התמונות בלע מילה מהנתיב** לתוך שם הקובץ.
